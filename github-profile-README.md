## Projects

### [Care Bot](https://github.com/shasankj/healthcare-chatbot) · [live demo](https://3-135-57-21.sslip.io/)
An insurance and pharmacy assistant that answers only from cited sources, says "I don't know" without evidence, and never gives medical advice. Hybrid RAG on Postgres with pgvector, an MCP server with four read-only tools for patient records, and a LangGraph agent wrapped in four layers of code-enforced guardrails, hosted on AWS EC2 with Docker and Caddy. 37 of 37 live end-to-end evaluation cases pass; 221 backend and 15 frontend tests.
*Claude Haiku 4.5 · LangGraph · MCP · FastAPI · pgvector · React · TypeScript* · [case study](https://shasankj.github.io/portfolio/projects/care-bot/)

### [Kenzo Pawsitive Academy](https://github.com/shasankj/kenzo-pawsitive-academy) · [live demo](https://dla0gzpanyc4d.cloudfront.net/)
A class-booking app where you pick an exact seat on a cinema-style map. DynamoDB conditional transactions make double-booking impossible, Postgres constraints protect the schedule, and SNS to SQS to SES sends confirmations without blocking a request. Serverless on AWS (22 Lambda functions), React frontend.
*React · Node.js · API Gateway · Lambda · RDS · DynamoDB · SNS/SQS/SES* · [case study](https://shasankj.github.io/portfolio/projects/kenzo-pawsitive-academy/)

### [This portfolio](https://github.com/shasankj/portfolio)
A static Astro site where every project is one Markdown file, with scroll-driven animated architecture diagrams, view transitions, a command palette and full light and dark themes. Lighthouse 99 to 100 on every page; accessibility scans pass in both themes.
*Astro · TypeScript · Tailwind · GSAP · Playwright*
